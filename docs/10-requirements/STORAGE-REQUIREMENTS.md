# Storage Requirements

## Purpose

Storage 域定义文件对象存储、文件元数据、文件内容读取、对象引用和分片上传需求。

Storage 负责“文件作为可复用资源如何被保存、读取和引用”，不负责具体业务内容规则。业务模块只保存稳定文件对象标识或自身语义包装后的引用，不保存底层对象键、物理路径或存储实现细节。

## Scope

覆盖：

- 后台普通文件上传。
- 大文件分片上传。
- 文件对象查询。
- 文件内容读取。
- 文件对象删除。
- 文件对象引用建立和清理。
- 本地文件和 S3 兼容对象存储适配。
- 文件对象状态和引用状态维护。

不覆盖：

- 通用 portal 上传入口。
- CDN 分发。
- workers 调用编排。
- 图片裁剪、压缩和水印。
- 视频转码。
- 音频处理。
- 在线预览转换。
- 文件安全扫描。
- 邮件通知。

## Functional Requirements

- 必须支持后台上传文件。
- 上传请求必须支持 `multipart/form-data`。
- 必须校验文件是否为空。
- 必须校验文件大小限制。
- 必须校验文件后缀或内容类型是否允许。
- 上传成功后必须保存文件内容。
- 上传成功后必须生成文件对象记录。
- 上传响应必须返回稳定文件对象标识、原始文件名、内容类型、文件大小和内容读取地址。
- 必须支持按文件对象标识读取文件内容。
- 文件内容读取必须输出正确 `Content-Type`。
- 必须支持按文件名、内容类型、引用归属类型、对象状态和引用状态查询文件对象。
- 管理界面必须支持查看文件对象的当前引用状态和引用信息。
- 必须支持业务模块建立文件对象引用。
- 必须支持业务模块清理文件对象引用。
- 必须支持删除文件对象。
- 已删除文件对象不得继续读取、引用或用于业务绑定。
- 必须支持初始化分片上传。
- 必须支持上传分片。
- 必须支持完成分片上传。
- 必须支持取消分片上传。
- 分片上传完成后必须生成普通文件对象。
- `uploadPart` 必须以 `multipart/form-data` 接收分片内容并落盘到临时内容位点，`complete` 按分片号顺序合并后生成最终对象。
- 取消分片上传时必须清理未完成分片内容，且会话不再产生可读对象。

## Business Rules

- 文件二进制内容不得进入业务数据库主数据。
- 业务模块不得保存底层对象键、物理路径或存储桶实现细节。
- 同一业务对象重复建立同一文件引用应保持幂等。
- `storage_object_reference` 只保存当前有效引用记录；解绑时直接删除对应引用记录。
- 文件对象存在引用时，不得被普通业务流程误判为可直接清理。
- 管理界面只允许删除无引用文件对象，不允许直接删除仍被引用的文件对象。
- 管理界面不承担引用关系编辑职责，不允许管理员手工修改文件对象引用状态或直接建立/移除引用关系。
- `storage_object` 不保留 `owner` 类字段；对象与业务对象的关系统一由 `storage_object_reference` 表达。
- `storage_object.reference_status` 由是否存在有效引用记录派生得到，不作为独立真相源。
- 清理最后一个引用后，文件对象必须回到未引用状态。
- 删除文件对象支持两条路径：管理界面对无引用对象发起显式删除，或系统对超过保留阈值的无引用对象发起自动删除。
- 显式删除和自动删除都必须先将对象推进到删除标记状态，再进入异步物理清理。
- 删除标记后的文件对象不得继续被读取、引用或用于业务绑定。
- 删除标记后的物理文件内容由异步计划任务执行最终删除，不要求删除接口同步完成物理清理。
- 文件内容读取不得要求调用方感知底层存储类型。
- 通用上传入口只面向后台；portal 需要上传时必须由具体业务模块定义专用上传入口并复用 Storage。
- 业务专用上传入口不得绕过 Storage 写入文件内容。
- Storage 不直接调用 workers。
- 业务域调用 workers 生成的文件内容，必须回到 Storage 创建文件对象并建立引用。
- 本地文件和 S3 兼容存储只能作为运行时底层存储实现，不改变业务语义。
- Portal 读取 Classics 文件对象时，必须由 Classics 先完成稿件生命周期和资源归属校验。

## Acceptance Criteria

- 管理员能在后台上传文件并获得文件对象标识。
- 空文件、超限文件和不允许类型文件会被拒绝。
- 已上传文件能通过内容读取地址稳定读取。
- 业务模块能建立和清理文件对象引用。
- 有引用的文件对象不会被误清理。
- 删除后的文件对象不能继续读取。
- 删除接口完成后，对象会先进入删除标记态；物理文件删除由后续计划任务完成。
- 长时间未引用的对象会被系统自动识别为 orphan，并进入删除流程。
- 大文件能通过分片上传完成并生成文件对象。
- 取消分片上传后，未完成内容不会生成可用文件对象。
