## 过程中发现并修复的问题

| 问题 | 原因 | 处理 |
| --- | --- | --- |
| Admin、Portal starter 启动失败 | 显式组件扫描遗漏 `discovery.interfaces.configure`，问答流执行器 Bean 未注册 | 两个 starter 均加入该配置包扫描，提交 `b31bef1fe` |
| FastGPT 问答长期停留“回答中” | bootstrap 创建的 Advanced App 为空工作流，`modules` 与 `edges` 均为空 | bootstrap 生成“流程开始 → AI 对话”工作流并绑定配置 LLM，提交 `bb23e95c0` |
| Portal 检索返回 500 | 新隔离 Elasticsearch 尚未创建 `discovery-search` 索引 | 通过后台受权限保护的重建接口初始化；后续检索为 HTTP 200 |
| 手工注入的 Admin Web dist 空白 | 本地产物使用 Vite 默认 `/admin/` 基路径，与部署 `/kuzhambu-admin/` 不一致 | 回归环境切换到服务器按 deploy 参数构建的 Admin Web 镜像 |
| 分类禁用错误判定仍有启用标签 | 分类仓储误用分类 Mapper 统计自身，而非统计关联标签 | 改为通过标签 Mapper 统计启用标签；单测与真实禁用复测通过 |
